# cs2-demo-analysis
A project where I practice analyzing some recordings of pro matches in the popular first-person shooter game Counter-Strike 2.

## Required packages

[Demo Parser 2](https://github.com/LaihoE/demoparser)

Install using the command: `pip install demoparser2` (python >= 3.8)

[Awpy](https://github.com/pnxenopoulos/awpy)

Install using the command: `pip install awpy` (python >= 3.11)
